# PixelPaws – A Endless Runner Game

## About the Project

**PixelPaws** is a 2D endless runner game developed using Java Swing. The player controls a character that must avoid obstacles, collect power-ups, and earn as many points as possible.

The game includes different characters, stages, difficulty settings, and a performance tracker. It is designed to run offline and does not require external game assets.

## Features

- **Endless Runner Gameplay** – Avoid obstacles and continue running to increase your score.
- **Character Selection** – Choose a character before starting the game.
- **Stage Selection** – Choose from different visual themes.
- **Difficulty Settings** – Select Default, Easy, Medium, or Hard mode.
- **Power-Ups** – Collect special boosters during gameplay.
- **Performance Tracker** – Review previous game records, including scores, themes, characters, and difficulty.
- **Best Score Saving** – Keep track of your highest score.
- **Pause and Resume** – Pause the game when needed.
- **Offline Gameplay** – Play without an internet connection.

## Power-Ups

The game includes the following power-ups:

| Power-Up | Description |
|---|---|
| Jump Boost | Allows the character to jump higher. |
| Wings | Allows the character to fly temporarily. |
| God Mode | Provides temporary invincibility. |
| Double Points | Doubles the points earned temporarily. |
| Dragon Breath | Automatically destroys obstacles temporarily. |

The game also includes a special portal bonus stage.

## How to Run

1. Download or clone the project.
2. Open the project folder in your preferred Java IDE or terminal.
3. Make sure the source file is named `PixelPaws.java`.
4. Open a terminal in the project folder.
5. Compile the program:

   ```bash
   javac PixelPaws.java
   ```

6. Run the game:

   ```bash
   java PixelPaws
   ```

## Game Controls

| Key | Function |
|---|---|
| SPACE | Jump |
| UP / W | Move to the upper road or jump |
| DOWN / S | Move down or duck |
| P | Pause the game |
| T | Open the theme selection |
| ESC | Return to the menu |
| LEFT / RIGHT | Select a character |
| ENTER | Confirm or start |

You can also use the mouse to interact with the game buttons and perform certain gameplay actions.

## Project Purpose

## Project Purpose

PixelPaws aims to provide an interactive and entertaining gaming experience through a simple endless runner game where players control a character, avoid obstacles, and aim to achieve higher scores. The project also serves as an application of Java programming concepts, particularly object-oriented programming, graphical user interfaces (GUI), event handling, game logic, and file handling. Through its development, the project demonstrates how these concepts can be combined to create a functional desktop game.
